A faster drop-in for makefun-site 1.0.0: a dependency-free static site generator that builds exactly the same output tree, byte for byte, in less CPU time. It uses a fused Markdown pass, cached slugs, and templates compiled to JavaScript instead of being walked as a tree on every page.

## Run it

```sh
node main.ts
```
